# Talentos Fantasma — Acompanhamento de Materiais

Página para acompanhar o farm dos talentos do tipo Fantasma (Tiers 1 a 4).

- **Banco de itens:** informe o Balance de cada item (aceita `2622`, `+500`, `-200`, `10k`). A falta de cada item é calculada sozinha, por tier.
- **Talentos:** marque a entrega item por item (por exemplo, 1 dos 3 itens de um talento) ou o talento inteiro.
- **Foco agora / Próximo:** o primeiro item da ordem de farm que ainda tem falta, e o seguinte.
- **Bônus liberados:** soma dos talentos concluídos nos tiers liberados, mais +1% de dano e +1% de defesa por tier liberado.
- **De onde vem cada item:** cada item mostra o ícone do jogo e o Pokémon que dropa ("todos Fantasma" = qualquer Pokémon do tipo Fantasma).
- **Nomes dos itens** (menu ⋯): tela com o ícone de cada item para preencher o nome e o Pokémon que dropa.
- **Registrar loot e previsão:** lance o que dropou (ou o total que tem); o histórico gera o ritmo dos últimos 7 dias e a previsão em dias.
- **Tiers em sequência:** cada tier libera com o anterior 100% concluído e o pagamento (T2 50.000.000, T3 200.000.000, T4 400.000.000 e nível 550). Entregar no talento desconta do Balance.
- **Abas:** Resumo, Itens (visões Falta e Depósito), Talentos, Bônus e Histórico.
- **Ordem de farm:** lista para ordenar os itens; o Foco segue essa ordem dentro do estoque até o tier escolhido em "Estocando até".
- **Tema escuro:** botão de sol/lua no topo; no menu ⋯ dá para escolher Auto, Claro ou Escuro.

No celular funciona como um app (abas embaixo; dá para adicionar à tela inicial). No desktop mostra tudo de uma vez.

## Onde ficam os dados

Nesta página, os dados ficam salvos no navegador de cada aparelho. Para levar a outro aparelho, use **⋯ → Copiar link com meus dados** e abra o link no outro aparelho. Também dá para copiar e restaurar um backup pelo mesmo menu.
